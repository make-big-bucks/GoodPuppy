补充
- 可以拖动puppy的位置
- 右键菜单「大小」可以放大 / 缩小 puppy，或恢复默认大小；所选大小会被记住，下次启动仍然生效
- 同房间的朋友现在是各自独立的窗口，可以分别拖动、散落在桌面各处
- 右键菜单「朋友摆放」可切换：
  - 「自由摆放」（默认）：每只 puppy 都能单独拖动，各自记住自己的位置
  - 「自动排布」：朋友们自动在你身边一字排开、不可单独拖动；你自己的 puppy 仍可自由拖
