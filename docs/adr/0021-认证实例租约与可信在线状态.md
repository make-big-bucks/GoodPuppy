# ADR-0021：认证实例租约与可信在线状态

- 状态：已采纳，后端已隔离验证，前端切换与远端部署待完成
- 日期：2026-10-02
- 关联：ADR-0012、ADR-0020

## 背景

Realtime 私有频道校验成员访问资格，但 Presence key 和 metadata 由客户端提供，不能据此证明宠物身份。单用户在线记录也不能区分同时运行的桌面实例。

## 决策

- 活跃实例使用私有租约，绑定 `auth.uid()`、真实 Auth session 和客户端实例；调用必须携带预期账号，阻止换账号后迟到请求作用于新身份。
- 实例版本与退役标记阻止旧激活/更新复活已退出实例；租约按服务端时间在两分钟后过期，多个实例独立退出。
- 成员关系或 Auth session 删除时级联清理租约；客户端不能直接修改租约表。
- 私有广播只提示读取快照，可信身份、外观与状态来自受成员检查保护的 RPC；禁止客户端直接 track/broadcast 制造可信状态。
- 原 `presence.current_room_id` 的房间记忆约定保留；在线展示切换到实例租约投影，前端完成切换前不部署本迁移。

## 后果

不依赖客户端声明的身份，退出和重连具有可验证版本边界；增加 RPC 与服务端租约查询，前端必须合并刷新并限频。隔离 SQL 测试证明授权及实例边界，不能替代真实 Realtime 接入与双客户端验收。

依据：[Presence 协议](https://supabase.com/docs/guides/realtime/protocol)、[Realtime 授权](https://supabase.com/docs/guides/realtime/authorization)。
