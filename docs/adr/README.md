# 架构决策记录（ADR）

本目录记录 GoodPuppy 项目中所有重要的架构决策。

## 格式说明

每条 ADR 采用 [Michael Nygard 模板](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html)，包含以下字段：

- **状态**：草案 / 已采纳 / 已废弃 / 已取代
- **背景**：决策面临的问题与约束
- **决策**：选择的方案
- **后果**：决策带来的正面与负面影响
