## 前置条件

- 真实服务测试使用独立 Supabase 测试项目和两个测试账号，迁移与客户端版本一致；生产变更须先取得具体授权。当前生产缺失的 SQL 为 `supabase/migrations/20261001051950_reconcile_room_authorization.sql`、`supabase/migrations/20261002073000_authenticated_presence_leases.sql`，迁移历史对齐另行批准。
- Windows 主机安装 README 的工具链，执行 `npm ci`、`npm run verify`、`npm run test:native` 和 `npm run build:windows`，保存完整退出结果；macOS 对应执行 `build:mac`。交叉类型检查不能替代链接/安装/运行。
- 双平台各需两块不同缩放的显示器；先画出桌面坐标布局，包含左右/上下布局与负坐标。普通单屏结果不能用于关闭多屏门禁。
- 修复分支已发布质量工作流；记录测试提交对应的 macOS、Windows、数据库任务链接及结果，不能引用其它提交的绿色运行。

当前产物证据（2026-10-02，源码提交 `ee4e5fb`）：macOS arm64 `build:mac` 成功，`.app` 的 Info.plist 检查与 DMG 完整性校验通过；仅 ad-hoc 签名，未安装验收或公证。构建产物位于 `src-tauri/target/release/bundle/`，不提交到 Git。

## 场景与预期

| 范围 | 操作 | 通过条件 |
|---|---|---|
| 启动/退出 | 分别在房间内、房间外退出后重启；进入再退出房间；托盘退出 | 仅实际处于房间时显示宠物与气泡；无房间启动不闪现宠物；正常退出保留房间且清理在线证明，日志显示关联退出回执 |
| Windows 窗口 | 首次进入创建自己/远程气泡，拖动父宠物，隐藏/恢复会客厅；成员离开再加入 | owner/置顶层级正确，气泡跟随，透明区域穿透而宠物可点击/拖动；离开销毁且同名重建无旧实例状态 |
| DPI 与布局 | 向两个方向跨屏拖动；在横向/纵向边界排布多只宠物，切换自由/半自由模式 | 宠物内容尺寸、排列底边与间距合理，气泡跟随与上下翻转无跳位；记录实际几何与缩放，确认最终窗口选择目标屏 |
| 屏幕变动 | 第二屏保存宠物位置后退出，拔屏再启动；重新接屏；跨屏触发上线提醒 | 不恢复到不可见位置；气泡/提醒落在目标屏可用区内，不侵入任务栏/Dock；有效位置仍能恢复 |
| 系统暂停 | 房间内实际休眠并唤醒；断网再联网；另一账号在暂停期间永久退出房间 | 恢复先复查资格并重建健康频道，旧在线证明不能沿用；失去资格不恢复旧房间；临时失败可重试，手动退出取消重试 |
| 私有频道 | 成员账号连接自己房间；非成员账号尝试相同主题；成员伪造用户 ID/在线 metadata；退房后保持旧连接 | 非成员无订阅/发布权限；伪造 payload 不改变可信身份/在线投影；退房后租约更新拒绝，旧证明过期且界面移除；同步核对禁止公共频道的项目设置 |
| 双客户端并发 | 两账号并发接受同一邀请、加入/永久退出；同账号两个实例在线后关闭其中一个，再关闭全部 | 成员关系与房间容量一致，重复请求无额外成员；旧版本不能覆盖新租约；关闭单实例不使另一实例离线，全部关闭后离线，界面与数据库收敛 |
| 消息恢复 | 断网期间另一客户端发送，恢复连接；重复补查；阅读旧页时发送新消息 | 消息完整且按时间/ID排序，无重复气泡/动画；新消息提示不打断旧页，回到最新后与服务端快照一致 |

每项分别记录通过/失败/未执行；生产授权、私有频道配置、Windows 实机、多屏或真实休眠缺任一条件时，保留对应台账为待验收。只更新取得实际证据的项目。
