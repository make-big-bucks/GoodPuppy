# 桌面坐标验收

对应验收项 20，当前契约见 [ADR-0022](../adr/0022-平台桌面坐标与逻辑内容尺寸.md)。依据项目实际依赖 Tao 0.35.3，两平台的 `PhysicalPosition` 不能直接视为同一种全局平面。

| 数据 | Windows | macOS |
|---|---|---|
| 位置、屏幕/工作区、父子偏移 | 全局物理像素 | 全局逻辑点 |
| 窗口内容宽高、DOM/命中形状 | 局部逻辑单位 | 局部逻辑单位 |
| `desktopScale` | 目标屏比例 | 1 |
| 新位置存档 | `desktop-physical-v2` | `desktop-logical-v2` |
| 旧逻辑存档 | 无法可靠换算，回退自动摆位 | 可继续读取 |

本地迁移已覆盖：主线程几何/工作区快照，带单位标记的创建定位，实际父子偏移，宠物自动布局、气泡避让、提醒卡片/间距、缩放底边保持和存档可见性。换算/协议/存档回归与 macOS 原生窗口生命周期通过；窗口间距内的水平 DPI 分界回归已补，间距归前窗、目标比例取最终横向位置。

Windows 所有目标与测试代码的 Rust 交叉检查已通过，修复了非 macOS 父子辅助函数缺少返回值的问题。本机环境核对（2026-10-02）：仅一块 Color LCD，系统报告 1470×918、60 Hz，无法完成真实双屏混合 DPI 验收。尚缺强证据：Windows 实际链接构建和实机；双平台混合 DPI 下的两方向跨屏、屏幕边界布局、气泡跟随/翻转、提醒位置、拔屏及存档恢复。上述门禁完成前不宣布本项完整验收；模拟换算不能替代实机结果。
